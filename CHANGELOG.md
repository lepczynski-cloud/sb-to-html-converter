## [0.1.0] - 2026-10-04

### Added

- Polish and English browser interface with a remembered language choice.
- Drag-and-drop conversion of `.sb`, `.sb2`, and `.sb3` projects to standalone HTML.
- Optional Turbo mode, interpolation, autoplay, player controls, fullscreen, and cloud-variable behavior.
- A downloadable single-file converter that runs locally in a modern browser.
- Reproducible build based on the pinned TurboWarp Packager `v3.13.0` tag.
- Cloudflare Workers static-assets configuration and Git-based deployment instructions.
- GitHub Actions workflows for verification, build artifacts, and tagged releases.
