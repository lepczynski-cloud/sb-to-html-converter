# Privacy / Prywatność

## Polski

Wybrany plik Scratch jest odczytywany i przetwarzany lokalnie w przeglądarce.
Aplikacja nie wysyła projektu do własnego serwera i nie wymaga konta.

Hosting Cloudflare może przechowywać standardowe techniczne logi żądań zgodnie
z własnymi zasadami. Wygenerowana gra może łączyć się z Internetem, jeżeli projekt
korzysta ze zmiennych chmurowych albo niestandardowych rozszerzeń. Kod
niestandardowych rozszerzeń działa w wygenerowanej grze bez sandboxa. Domyślnie
konwerter ustawia zmienne chmurowe jako lokalne, aby plik wynikowy lepiej działał
offline.

## English

The selected Scratch file is read and processed locally in the browser. The app
does not upload the project to its own server and does not require an account.

Cloudflare hosting may keep standard technical request logs under its own terms.
A generated game may access the Internet when the project uses cloud variables
or custom extensions. Custom extension code runs without a sandbox in the
generated game. By default, the converter stores cloud variables locally
so the generated file works better offline.
