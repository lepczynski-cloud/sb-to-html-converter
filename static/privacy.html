Prywatność

Wybrany projekt Scratch jest przetwarzany lokalnie w Twojej przeglądarce. Aplikacja nie wysyła pliku do własnego serwera.

Dane projektu

Pliki .sb, .sb2 i .sb3 są odczytywane przez kod uruchomiony w przeglądarce. Gotowy plik HTML jest tworzony na urządzeniu użytkownika i pobierany bez pośrednictwa serwera aplikacji.

Połączenia zewnętrzne

Podczas konwersji niestandardowe rozszerzenia zapisane w projekcie mogą zostać pobrane z ich oryginalnych adresów. Ich kod działa w wygenerowanej grze bez sandboxa, dlatego aplikacja prosi o potwierdzenie przed ich dołączeniem. Wygenerowana gra może łączyć się z Internetem, gdy korzysta ze zmiennych chmurowych albo zewnętrznych usług. Domyślnie zmienne chmurowe są ustawiane jako lokalne.

Hosting

Publiczna strona jest hostowana w Cloudflare. Cloudflare może przetwarzać standardowe techniczne dane żądań zgodnie ze swoimi warunkami i polityką prywatności. Aplikacja nie dodaje własnych narzędzi analitycznych, kont użytkowników ani reklam.

Wersja offline

Pobrany konwerter offline jest pojedynczym plikiem HTML. Sam plik projektu nie jest wysyłany do serwera, jednak projekty z niestandardowymi rozszerzeniami nadal mogą wymagać sieci podczas konwersji.

Privacy

The selected Scratch project is processed locally in your browser. The app does not upload the file to its own server.

Project data

.sb, .sb2 and .sb3 files are read by code running in the browser. The finished HTML file is created on the user's device and downloaded without passing through the app's server.

External connections

During conversion, custom extensions stored in a project may be downloaded from their original addresses. Their code runs without a sandbox in the generated game, so the app asks for confirmation before including them. A generated game may access the Internet when it uses cloud variables or external services. Cloud variables are set to local storage by default.

Hosting

The public website is hosted on Cloudflare. Cloudflare may process standard technical request data under its own terms and privacy policy. The app adds no analytics, user accounts or advertising.

Offline version

The downloadable offline converter is one HTML file. The project file is not uploaded to a server, although projects with custom extensions may still need network access during conversion.
