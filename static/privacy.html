Privacy

The selected Scratch project is processed locally in your browser. The application does not upload the project file to its own server.

Project data

Scratch files are read by code running in the browser. The generated HTML file is created on the user's device and downloaded directly.

External connections

Custom extensions stored in a project may be downloaded from their original addresses during conversion. Their code runs without a sandbox in the generated game. A generated game may also access the Internet when it uses cloud variables or external services.

Website hosting

The hosting provider may process standard technical request data under its own terms. This application does not add analytics, user accounts, or advertising.

Offline converter

The standalone converter is a single HTML file. Project files remain local, although projects with custom extensions can still require network access during conversion.
